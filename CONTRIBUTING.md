# Contribuciones

Las contribuciones son bienvenidas mediante pull request.

1. No incluya RFC, contraseñas, captchas, cookies ni respuestas autenticadas sin sanitizar.
2. No agregue operaciones que abran o acusen notificaciones pendientes dentro del flujo de recolección.
3. Agregue pruebas unitarias y ejecute `composer dev:test`.
4. Mantenga compatibilidad con la versión mínima de PHP declarada en `composer.json`.
